# Qwen3.5-4B LM Head 蒸馏范围实验汇总

## 1. 实验目的

本实验研究：在同一个 W4A16 GPTQ 量化模型上，只训练 `lm_head` 的 LoRA 时，蒸馏位置范围和参数范围如何影响数学推理、代码生成与知识任务。

实验对比五种方法：

| 方法 | 蒸馏位置 | LoRA 参数范围 | Rank | 训练位置数 |
|---|---|---|---:|---:|
| `baseline` | 不训练 LoRA | 无 | - | - |
| `all_tokens` | 所有有效 token | 完整 `lm_head` | 8 | 1,140,582 |
| `connectives_end` | 逻辑连接词及推理结束位置 | 完整 `lm_head` | 8 | 42,367 |
| `end_think_full` | 每条样本的 `</think>` 位置 | 完整 `lm_head` | 8 | 128 |
| `end_think_row` | 每条样本的 `</think>` 位置 | 仅对应输出行 | 1 | 128 |

四种 LoRA 的 `target_modules` 都是 `lm_head`。前三种 LoRA 的 `r/alpha` 为 `8/8`；`end_think_row` 为 `1/1`。

## 2. 统一配置

### 模型与训练

| 配置项 | 值 |
|---|---|
| Teacher | `Qwen/Qwen3.5-4B` BF16 |
| Student | `Qmodel/Qwen3.5-4B-HiF4-GPTQ-s1k-head-512x4096` |
| 权重/激活精度 | W4A16 |
| 训练数据 | `simplescaling/s1K-1.1` |
| 训练样本数 | 128 |
| 最大训练长度 | 16,384 |
| Epoch | 10 |
| 学习率 | `1e-4` |
| Logits chunk size | 256 |
| Seed | 42 |
| Attention implementation | SDPA |

### 评测

| 配置项 | 值 |
|---|---|
| 任务 | AIME25 Avg@5、LiveCodeBench v6、MMLU-Pro |
| MMLU-Pro 样本数 | 1,000 |
| 重复次数 | 3 |
| 三次生成 seed | 42、43、44 |
| Temperature / Top-p / Top-k | 0.7 / 0.8 / 20 |
| 最大上下文 / 最大生成长度 | 32,768 / 32,768 |
| Batch size | 128 |
| Tensor parallel | 4 |

AIME 和 LiveCodeBench 是采样生成任务，因此三次结果存在明显波动；MMLU-Pro 更稳定。

## 3. 训练结果

| 方法 | Epoch 1 loss | Epoch 10 loss | 相对下降 |
|---|---:|---:|---:|
| `all_tokens` | 0.591735 | 0.591646 | 0.015% |
| `connectives_end` | 1.334233 | 1.334024 | 0.016% |
| `end_think_full` | 0.335632 | 0.334828 | 0.239% |
| `end_think_row` | 0.335632 | 0.327669 | 2.373% |

不同方法的 loss 来自不同数量和类型的位置，绝对值不能直接横向比较。能直接比较的是各自训练过程中的下降幅度。`end_think_row` 的下降最明显，但这不等于下游指标最好。

## 5. 相对 Baseline 的平均变化

| 方法 | AIME25 | LiveCodeBench | MMLU-Pro |
|---|---:|---:|---:|
| `all_tokens` | +0.0133 | -0.0133 | -0.0007 |
| `connectives_end` | +0.0111 | -0.0038 | +0.0000 |
| `end_think_full` | **+0.0222** | -0.0210 | -0.0027 |
| `end_think_row` | +0.0044 | -0.0267 | -0.0037 |

这里按相同 repeat 的生成 seed 配对后计算差值，再对三次差值求平均。

## 6. 结果分析

### AIME

四种 LoRA 的三次平均分都高于 baseline，其中 `end_think_full` 最好：

- `0.5422 → 0.5644`，平均提高 0.0222。
- 三次中两次高于 baseline，一次低于 baseline。
- `connectives_end` 的均值略低于 `end_think_full`，但三次波动最小。

这说明对完整 `lm_head` 蒸馏 `</think>` 位置可能对数学推理有小幅正向作用。但提升小于单次评测的典型波动，三次实验还不足以证明稳定、显著的提升。

### LiveCodeBench

没有一种 LoRA 的三次平均分超过 baseline：

- baseline 均值最高，为 0.2895，但标准差也最大。
- `connectives_end` 均值为 0.2857，只低 0.0038，同时标准差从 0.0429 降到 0.0057。
- `end_think_full` 和 `end_think_row` 分别下降 0.0210 和 0.0267。

因此当前结果不支持“LM Head 蒸馏提高代码能力”。`connectives_end` 的主要表现是三次结果更稳定，而不是平均分提高。由于 baseline 的 Repeat 2 异常低，单看某一次 repeat 会得到相反结论，必须使用三次均值。

### MMLU-Pro

五种方法的均值集中在 0.7840～0.7877：

- `connectives_end` 与 baseline 均为 0.7877。
- 其余 LoRA 相对 baseline 下降 0.0007～0.0037。
- 这些差值只有 1～4 道题，且 LoRA 组自身波动更大。

可以认为本实验没有观察到明确的 MMLU-Pro 能力变化。

### 蒸馏范围的整体判断

- `end_think_full`：AIME 平均收益最大，但 LCB 和 MMLU 略降，适合继续验证数学收益。
- `connectives_end`：三项最均衡；AIME 小幅提高、LCB 均值近似持平且明显更稳定、MMLU 持平。
- `all_tokens`：AIME 小幅提高，LCB 略降，没有显示全 token 蒸馏的额外优势。
- `end_think_row`：参数和训练位置最少、训练 loss 降幅最大，但三项下游指标均不占优，说明只优化一个输出行过于局部。

综合当前三次结果，`connectives_end` 是最稳妥的范围，`end_think_full` 是 AIME 上最值得继续验证的范围；没有方法在三项任务上形成一致提升。

## 8. 最终结论

1. LM Head LoRA 没有带来跨任务一致提升。
2. `end_think_full` 的 AIME 三次均值最高，比 baseline 高 0.0222，但证据仍弱，需要更多重复实验确认。
3. LiveCodeBench 的最高均值仍是 baseline；`connectives_end` 接近 baseline，并显著降低三次波动。
4. MMLU-Pro 基本不变，说明这些 LoRA 没有明显改变通用知识能力。
5. 训练 loss 降得更多不代表下游效果更好，`end_think_row` 是最直接的反例。
6. 当前最值得保留的两个方案是：偏稳定性的 `connectives_end`，以及偏 AIME 的 `end_think_full`。
