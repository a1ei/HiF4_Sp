## 对比结论

- `fp32w_fp32a` 的 AIME 和 LiveCodeBench 最好。
- `bf16w_bf16a` 的 MMLU-Pro 最高，为 72.10%，但只比 `fp32w_fp32a` 高 0.57 个百分点，小于单次评测约 0.82 个百分点的标准误，不能据此判断它真实更好。
- 在相同 BF16 权重下，把激活从 BF16 改成 HiF4 后，AIME pass@1 下降 5.33 个百分点，MMLU-Pro 下降 1.73 个百分点，LiveCodeBench 上升 0.57 个百分点。
- SmoothQuant 对 HiF4 激活的 AIME 有小幅改善：pass@1 上升 1.33 个百分点、avg@n 上升 2.67 个百分点；LiveCodeBench 不变，MMLU-Pro 下降 0.40 个百分点。
