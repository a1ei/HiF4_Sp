# Qwen3.5-4B GPTQ End-Think LoRA 复现实验汇总

## 1. 实验目的

本实验用于复核：在同一个 Qwen3.5-4B HiF4 GPTQ 量化模型上加入 `end-think` LoRA 后，AIME25、LiveCodeBench 和 MMLU-Pro 是否稳定改善。

对比方法只有两种：

| 方法 | 模型 | LoRA |
|---|---|---|
| `gptq` | `Qwen3.5-4B-HiF4-GPTQ-s1k-head-512x4096` | 无 |
| `gptq_end_think_lora` | 同一个 GPTQ 模型 | `Qwen3.5-4B-HiF4-GPTQ-end-think-lora` |

两种方法分别在 W4A16 和 W4A4 下评测，每种配置使用 seed 42、43、44 重复三次。相同 repeat 使用相同 seed，因此可以进行配对比较。

## 2. LoRA 配置与训练结果

该 LoRA 只作用于 `lm_head`：

| 配置项 | 值 |
|---|---|
| Target module | `lm_head` |
| Rank / Alpha | 1 / 1 |
| Dropout | 0 |
| Bias | none |
| 训练目标 | 提高推理结束位置的目标 token 概率 |

训练前后指标：

| 指标 | 训练前 | 训练后 | 变化 |
|---|---:|---:|---:|
| 正位置目标概率 | 0.8247 | 0.9275 | +0.1029 |
| 正位置 Top-1 率 | 0.9375 | 1.0000 | +0.0625 |
| 负位置目标概率 | 3.53e-7 | 5.32e-7 | 仍接近 0 |
| 负位置误触发率 | 0 | 0 | 不变 |

最佳验证损失为 0.2432。训练目标本身达成：LoRA 提高了正确推理结束位置的目标概率，没有在负位置产生可见的误触发。

## 3. 统一评测配置

| 配置项 | 值 |
|---|---|
| 数据集 | AIME25 Avg@5、LiveCodeBench v6、MMLU-Pro |
| MMLU-Pro 样本数 | 1,000 |
| Repeat seed | 42、43、44 |
| Temperature / Top-p / Top-k | 0.7 / 0.8 / 20 |
| 最大上下文 / 最大生成长度 | 32,768 / 32,768 |
| Batch size | 128 |
| Tensor parallel | 4 |
| W4A16 激活量化 | 不启用 |
| W4A4 激活量化 | HiF4 |

需要特别注意：W4A16 和 W4A4 使用的是同一个 W4A16 训练的 LoRA。W4A4 只是在评测阶段启用激活量化，并没有使用针对 W4A4 重新训练的 LoRA。

## 4. W4A16 结果

### 三次原始结果

| 指标 | 方法 | Repeat 1 | Repeat 2 | Repeat 3 | 均值 | 标准差 |
|---|---|---:|---:|---:|---:|---:|
| AIME25 | GPTQ | 0.5933 | 0.5533 | 0.5667 | 0.5711 | 0.0204 |
| AIME25 | GPTQ + LoRA | 0.5733 | 0.5867 | 0.6067 | **0.5889** | 0.0168 |
| LCB | GPTQ | 0.2686 | 0.3086 | 0.2800 | 0.2857 | 0.0206 |
| LCB | GPTQ + LoRA | 0.3086 | 0.2971 | 0.2971 | **0.3010** | 0.0066 |
| MMLU-Pro | GPTQ | 0.7920 | 0.7850 | 0.7820 | **0.7863** | 0.0051 |
| MMLU-Pro | GPTQ + LoRA | 0.7670 | 0.7850 | 0.7940 | 0.7820 | 0.0137 |

### 相同 seed 的配对变化

差值定义为 `LoRA - GPTQ`：

| 指标 | Repeat 1 | Repeat 2 | Repeat 3 | 平均变化 | 胜/平/负 |
|---|---:|---:|---:|---:|---:|
| AIME25 | -0.0200 | +0.0333 | +0.0400 | **+0.0178** | 2 / 0 / 1 |
| LCB | +0.0400 | -0.0114 | +0.0171 | **+0.0152** | 2 / 0 / 1 |
| MMLU-Pro | -0.0250 | 0.0000 | +0.0120 | -0.0043 | 1 / 1 / 1 |

### W4A16 判断

- AIME 均值从 0.5711 提高到 0.5889，平均增加 0.0178。
- LCB 均值从 0.2857 提高到 0.3010，平均增加 0.0152。
- AIME 和 LCB 都是三次中两次提高、一次下降，方向偏正，但不是稳定全胜。
- LCB 的标准差从 0.0206 降到 0.0066，LoRA 组的三次结果更集中。
- MMLU 平均下降 0.0043，三次方向不一致，可以视为基本持平。

因此，W4A16 上可以说 LoRA 对 AIME 和 LCB 有小幅正向信号，但三次样本还不足以证明稳定、显著的提升。

## 5. W4A4 结果

### 三次原始结果

| 指标 | 方法 | Repeat 1 | Repeat 2 | Repeat 3 | 均值 | 标准差 |
|---|---|---:|---:|---:|---:|---:|
| AIME25 | GPTQ | 0.5067 | 0.4667 | 0.5000 | **0.4911** | 0.0214 |
| AIME25 | GPTQ + LoRA | 0.4733 | 0.4933 | 0.4667 | 0.4778 | 0.0139 |
| LCB | GPTQ | 0.2171 | 0.1943 | 0.2286 | **0.2133** | 0.0175 |
| LCB | GPTQ + LoRA | 0.2057 | 0.2229 | 0.2000 | 0.2095 | 0.0119 |
| MMLU-Pro | GPTQ | 0.7600 | 0.7630 | 0.7670 | 0.7633 | 0.0035 |
| MMLU-Pro | GPTQ + LoRA | 0.7660 | 0.7690 | 0.7830 | **0.7727** | 0.0091 |

### 相同 seed 的配对变化

| 指标 | Repeat 1 | Repeat 2 | Repeat 3 | 平均变化 | 胜/平/负 |
|---|---:|---:|---:|---:|---:|
| AIME25 | -0.0333 | +0.0267 | -0.0333 | -0.0133 | 1 / 0 / 2 |
| LCB | -0.0114 | +0.0286 | -0.0286 | -0.0038 | 1 / 0 / 2 |
| MMLU-Pro | +0.0060 | +0.0060 | +0.0160 | **+0.0093** | 3 / 0 / 0 |

### W4A4 判断

- AIME 和 LCB 都是一次提高、两次下降，三次平均也下降。
- MMLU 三次全部提高，均值增加 0.0093，即 1,000 道题中平均约多对 9.3 道。
- 因为 LoRA 是在 W4A16 条件下训练的，W4A4 结果同时混入了训练精度与推理精度不匹配的影响。

因此，当前 LoRA 在 W4A4 上没有改善生成式推理任务；MMLU 有一致的小幅收益，但不能据此认为 LoRA 整体有效。

## 6. LoRA 是否有效

### 支持有效的证据

1. LoRA 的直接训练目标明显改善：正位置概率从 0.8247 提高到 0.9275，Top-1 率达到 1.0。
2. W4A16 的 AIME 三次均值提高 0.0178，三次中两次胜出。
3. W4A16 的 LCB 三次均值提高 0.0152，三次中两次胜出，并且波动明显降低。
4. W4A4 的 MMLU 三次均提高，平均增加 0.0093。

### 不支持稳定有效的证据

1. 没有一个主要生成指标在三次重复中全部提高。
2. W4A16 的 AIME 和 LCB 提升幅度与采样波动处于相近量级。
3. W4A4 的 AIME 和 LCB 平均下降，说明收益不能跨激活精度保持。
4. W4A16 MMLU 没有收益，W4A4 MMLU 的收益也没有与生成任务同步。
5. W4A4 使用的不是针对 W4A4 训练的 LoRA，当前设计不能公平回答“W4A4 专用 LoRA 是否有效”。

### 最终结论

当前最准确的结论是：

> `end-think` LoRA 在 W4A16 上对 AIME 和 LiveCodeBench 显示了可复现但较弱的正向信号；它不是跨精度、跨任务稳定有效。W4A4 上没有观察到 AIME/LCB 收益。

如果把“有效”定义为三次平均提升，那么 W4A16 的 AIME 和 LCB 有效；如果把“有效”定义为每次重复都提升且能跨精度保持，那么当前 LoRA 无效。

基于现有数据，建议将它描述为“W4A16 上有小幅收益倾向”，不要描述为“已经证明稳定提升”。
